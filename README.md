# CreditWise – Loan Approval Prediction System

## Overview
CreditWise is a machine learning mini-project developed using JupyterLab to predict loan approval through supervised learning classification algorithms.

## Algorithms Used
- K-Nearest Neighbors (KNN)
- Logistic Regression
- Naive Bayes

## Features
- Exploratory Data Analysis (EDA)
- Data preprocessing and feature engineering
- Binary classification
- Model evaluation using Precision, Recall, and F1-score

## Technologies
- Python
- JupyterLab
- Pandas
- NumPy
- Matplotlib / Seaborn
- Scikit-learn

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open `CreditWise_Loan_Approval.ipynb` in JupyterLab.
4. Run the notebook cells in order.

## Project Type
Machine Learning Mini-Project

## Disclaimer
This project is for educational purposes only. Predictions are not financial advice and should not be used as the sole basis for real loan decisions.
